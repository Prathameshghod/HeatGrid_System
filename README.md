# heatgrid_java

This repository is an initialized full-stack Java project skeleton.

Structure:
- `backend` — Spring Boot (Maven) backend
- `frontend` — React + Vite frontend

Quick start

Backend (from `heatgrid_java`):

```bash
cd backend
mvn clean package
mvn spring-boot:run
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Notes
- These are skeleton files. Run the above commands to install dependencies and start each part.
- Adjust Java version and Spring Boot version in `backend/pom.xml` as needed.
